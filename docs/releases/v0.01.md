# v0.01 — M0 探针

首个公开预发布版本，只验证链路，不是日常可用版本。

## 内容

- 初始化 CabinCanvas 工程：Kotlin + Jetpack Compose + Material 3。
- `:app`：产品壳首页，显示 M0 状态与版本信息。
- `:probe:c`：M0 探针 C
  - 绑定 `com.baidu.carlife.oppo/CarlifeConnectService`
  - 手工处理 `ICarLifeCastManager` transaction
  - `prepareCast` → `VirtualDisplay` → `Presentation` → 色条 + 5 个按钮
  - 记录触摸（注入/回调）和 PCM 音频
  - 分享 `probe.log`

## 安装

```powershell
adb install -r app-debug.apk
adb install -r c-debug.apk
```

## 已知限制

- 预发布使用 debug 签名，不能作为最终升级基线。
- 未实现车机桌面、应用投屏、媒体/电话/通知/语音。
- 百度引擎是否接受第三方包名、CastConfig 字段顺序、触摸与音频路径，均需真车 M0 验证。
- 无线 CarLife 未验证。
