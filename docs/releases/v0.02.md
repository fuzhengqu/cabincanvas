# v0.02 — 完整 UI 预览

首个包含完整车机 UI 的版本。仍然不连接真实 CarLife，先验证布局、交互和信息架构。

## 内容

- **车机首页**：状态栏、左 Dock / 底部胶囊、地图卡（Canvas 手绘假地图）、媒体卡、建议卡、时钟天气、通知卡、页码点。
- **应用中心**：读取真实已安装应用（图标/名称），分类、搜索、长按菜单、应用详情，3/4/6/8 列自适应。
- **投屏容器**：全屏、兼容 16:9、手机比例、分屏、沉浸模式，悬浮 Dock。
- **媒体**：大封面、歌词、进度、播放控制、播放队列、来源切换。
- **电话**：最近通话、联系人、拨号盘、来电/通话中浮层。
- **通知**：列表、清空、快捷回复、模拟通知、Toast。
- **语音**：聆听动画、命令示例、结果反馈。
- **设置**：连接、显示、声音、应用、语音、通知、桌面、校准、关于。
- **卡片管理**：显示/隐藏、尺寸、添加。
- **校准**：四边安全区、overscan、保存。
- **诊断**：引擎/传输/显示/触摸/音频状态、日志、打开 M0 探针。
- **引导**：5 步、可跳过。
- **主题/壁纸**：深空/晨雾/自动、6 张内置壁纸。

## 自适应

`CarViewport` 根据 `widthPx × heightPx × dpi` 计算：

- `COMPACT`（<960dp）：800×480，3 列，左 Dock 56dp。
- `MEDIUM`（960–1439dp）：1024×600 / 1280×720 / 1080p@240，4 列。
- `EXPANDED`（1440–1919dp）：1920×720 / 2K，6 列。
- `ULTRA`（≥1920dp）：4K / 6K / 8K，8–10 列。
- 超宽屏自动底部胶囊；竖屏自动底部栏 + 2 列。

## 预览

`CarPreviewActivity` 支持：

- 800×480、1024×600、1280×720、1920×720、1920×1080、2560×1440、3840×2160、6016×3384、7680×4320、1080×1920 竖屏。
- DPI：120 / 160 / 213 / 240 / 320 / 480。
- 主题、壁纸、布局切换。
- `--es screen SETTINGS` 可直接打开指定页面（调试用）。

## 已知限制

- 不连接真实 CarLife；投屏内容为 UI 预览。
- 应用窗口内容为模拟界面，真实投屏在 M1 接入。
- 4K/6K/8K 目前验证布局与预览；实际流分辨率受车机/编码器限制。
- 预发布仍使用项目 release 签名，可覆盖升级。
