# v0.05 — 设置持久化 + 通知回复验证

## 内容

- **DataStore 持久化**：主题、壁纸、桌面布局、overscan 校准值写入 `car_settings`，进程重启后恢复。
- **通知快捷回复测试**：诊断页新增“测试通知回复”，发出一条带平台 `RemoteInput` 的通知；在通知中心回复后，`ReplyEchoReceiver` 记录文本并打印 `CabinCanvasReply`。
- 设置页/主题页/校准页的修改立即写入 DataStore，不再只留在内存。
- 车机 UI 与 M1 数据源保持 v0.04 的行为。

## 验证

- 构建、lint、release 已通过。
- `CarPreviewActivity` 启动时读取 DataStore；修改主题/壁纸/布局后强制停止进程，再启动应保持。
- 通知回复：在诊断页触发测试通知 → 通知中心“快捷回复” → 发送 → `adb logcat -s CabinCanvasReply` 应出现 `reply=<文本>`。

## 已知限制

- Pixel 在构建时掉线，持久化/回复的真机回归需重新连接后补测。
- 通知回复只对带 RemoteInput 的通知生效；普通通知只显示、不显示回复按钮。
