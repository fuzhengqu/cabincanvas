# v0.03 — UI 对比度与细节修正

v0.02 的首个真机截图暴露了手机端首页深色卡片标题对比度不足的问题；本版修正，并保持车机 UI 不变。

## 内容

- 修复手机端首页 `CabinCanvas` 标题、卡片标题在深色主题下颜色过暗的问题。
- 为手机端三张卡片显式设置 `contentColor`，避免 Material3 默认内容色在自定义深色容器上失效。
- 其余车机 UI、分辨率适配、预览器与 v0.02 一致。
